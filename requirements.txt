# Runtime dependencies, pinned to exact versions.
#
# Why exact pins and not a generated lock file: the heavy dependency here is
# PyTorch, whose wheels differ by platform (a Linux install pulls CUDA
# packages that do not exist on macOS). A lock file generated on one machine
# would be wrong on the other, so this file pins what the application
# actually imports, and the packages that decide how the model loads, and
# leaves the rest of the tree to pip. It needs no tooling beyond pip.
#
# To upgrade: change a version here, reinstall, and run the tests. The
# retrieval tests assert which result ranks first, so a change that moves the
# embeddings will show up there.
#
# Install dev/test tools with requirements-dev.txt.
